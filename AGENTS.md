## Essential commands

```sh
nh os switch           # rebuild system config (not nixos-rebuild)
nh home switch         # rebuild home-manager (not home-manager switch)
doas <cmd>             # privilege escalation (sudo is disabled)
conf                   # alias: cd ~/nixos
```

## Structure

- `flake.nix` — single‑host flake; home-manager and nixos config in the same repo
- `configuration.nix` — system‑level config (boot, networking, services, system packages)
- `hardware-configuration.nix` — **auto‑generated, do not edit** (nixos-generate-config)
- `home.nix` — user‑level config, imports everything under `configs/`
- `packages.nix` — user package list (imported by `home.nix`)
- `configs/<name>.nix` — individual module files, each may pair with `configs/<name>/` for dotfiles via `xdg.configFile`
- `configs/nvim/` — Neovim config (symlinked to `~/.config/nvim`)

## Conventions

- `doas` replaces `sudo` everywhere (configuration.nix:150)
- `nh` replaces raw `nixos-rebuild` / `home-manager` — flake path is baked into `programs.nh.flake`
- `hardware-configuration.nix` is regenerated by `nixos-generate-config` — make changes in `configuration.nix` instead
- Avoid `system.stateVersion` downgrades; both system and home stateVersion are `26.05`
- Theme generation: matugen templates live in `configs/matugen/templates/`, applied by post‑switch scripts
- Desktop: Hyprland + UWSM (`programs.hyprland.withUWSM = true`); login via `services.displayManager.ly`
- `xdg.configFile` is the standard mechanism for symlinking dotfile directories (avoid manual symlinks)

## Packages

System packages live in `configuration.nix:environment.systemPackages`.
User packages live in `packages.nix` (imported by `home.nix`).

`nixpkgs.config.allowUnfree = true` is set in both configs.

## Testing / verification

After any `.nix` change, run:

```sh
nh os switch          # system changes
nh home switch        # user/home-manager changes
```

There are no CI tests, formatters, or linters configured in this repo. Nix evaluation catches most errors at build time.
